# Tara Rose Salon content planner (website)

Live at **https://marketing-trls.github.io/**

A read-only view of the content plan: platform grids (Instagram, Facebook, TikTok, YouTube Shorts,
LinkedIn, Google Business), the Caption pack and the Campaign calendar.

## Update it
1. In the Claude planner, open **Caption pack** and click **Export for website**. Save `posts.json`.
2. Here on GitHub, open the `data` folder, click **Add file → Upload files**, drop `posts.json`, **Commit changes**.
3. The site updates in about a minute.

This repository is public: anyone with the link can see the website. The planner code, prompts and
brand rules stay in the private `hanneh-marketing` repository.
